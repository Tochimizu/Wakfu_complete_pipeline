//___Project descriptio
# 🎯 Project: Spatially-Adapted Behavior Cloning Bot (Log + Vision Hybrid)

## 1. Objective

Build a system that:

1. Reconstructs full game state using:

   * Server logs (identity + stats)
   * Screen vision (positions on fixed isometric grid)
2. Learns player behavior via imitation (behavior cloning)
3. Replays **action sequences from similar past states**
4. BUT adapts actions spatially when enemy positions differ
5. Executes actions in real time with controlled timing (≥ 0.01s per action)

---

# 2. Core Design Principle

> The bot reuses past *strategies*, not exact coordinates.

So instead of:

* “Click tile (6,7) because I did before”

It does:

* “Attack the closest equivalent enemy in this new configuration”

## 8.1 Target resolution rules

### Rule 1: role-based matching

| Intent               | Runtime resolution             |
| -------------------- | ------------------------------ |
| nearest_enemy        | closest enemy in current state |
| lowest_hp_enemy      | min HP enemy                   |
| highest_threat_enemy | heuristic score                |
| same_type_enemy      | match by log entity type       |

## 8.2 Mapping function

```python id="x8m2qp"
def resolve_target(intent, state):
    if intent.target_role == "nearest_enemy":
        return closest_enemy(state)

    if intent.target_role == "lowest_hp_enemy":
        return min(state.enemies, key=lambda e: e.hp)

    if intent.target_role == "same_type_enemy":
        return match_by_type_and_distance()
```

# -----------------------------
# PARSER → EVENT MAPPER
# -----------------------------
class FightLogParser:
    FL_REGEX = re.compile(
        r"\[_FL_\]\s+fightId=(\d+)\s+"
        r"(.*?)\s+breed\s+:\s+(\d+)\s+\[([-\d]+)\]\s+"
        r"isControlledByAI=(true|false)\s+obstacleId\s+:\s+([-\d]+)\s+"
        r"join the fight at\s+\{Point3\s+:\s+\(([-\d]+),\s+([-\d]+),\s+([-\d]+)\)\}"
    )

    @staticmethod
    def parse(line: str) -> Optional[EntitySpawned]:
        if "[_FL_]" not in line:
            return None

        m = FightLogParser.FL_REGEX.search(line)
        if not m:
            return None

        fight_id, name, breed, entity_id, is_ai, obstacle_id, x, y, z = m.groups()

        return EntitySpawned(
            fight_id=fight_id,
            entity_id=entity_id,
            name=name.strip(),
            breed=int(breed),
            is_ai=(is_ai == "true"),
            obstacle_id=int(obstacle_id),
            position={"x": int(x), "y": int(y), "z": int(z)},
        )
